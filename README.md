# VentiqAI — AI-Powered Air Quality Intelligence Platform

VentiqAI is an AI-powered web platform designed to provide location-based Air Quality Index (AQI) insights and predictions using machine learning, real-time environmental data, and interactive visualizations.

The project was developed as a **team project during an AI/ML Hackathon**, combining a web-based frontend, Flask backend, external APIs, and a machine learning prediction pipeline.

---

## 🚀 Features

- 🌍 Location-based AQI information
- 📊 Interactive AQI and trend visualizations
- 🗺️ Interactive map-based location visualization
- 🌦️ Real-time environmental/weather data integration
- 🤖 Machine Learning-based AQI prediction
- 📍 Browser geolocation with IP-based fallback
- 📈 Historical and forecast-based insights
- 🔄 Frontend-backend API integration
- ☁️ Cloud deployment support

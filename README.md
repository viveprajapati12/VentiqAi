VentiqAI — AI-Powered Air Quality Intelligence Platform

VentiqAI is an end-to-end Machine Learning platform that predicts the Air Quality Index (AQI) using historical environmental data and presents actionable insights through an intuitive web interface.

Built with a production-oriented workflow, the project covers the complete ML lifecycle—from data preprocessing and model training to API development, cloud deployment, and interactive visualization.
